# Iteration 2 Milestone Reports

This folder contains one living context report for each milestone that has actually started.

Examples:

```text
I2.1.md
I2.2.md
I2.3.md
```

Do not create nine empty milestone files in advance. When Codex starts a milestone, it copies the structure from `docs/team/MILESTONE_REPORT_TEMPLATE.md` into the corresponding `I2.X.md` file.

Codex updates the active report:

- after an accepted feature slice;
- before changing to the next milestone;
- at the end of a member’s week;
- after project-manager review;
- after integration into `development/fullstack` or `main`.

The report summarizes evidence; it does not replace Git, source code, migrations, or test output. Never include credentials, private environment values, student private data, source submissions, hidden tests, or runtime-storage paths.
